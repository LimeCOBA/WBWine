# WB Wine

Работай в этом репозитории локально. Публикация в Git требует просьбы пользователя.

Семь кабинетов имеют отдельные точки входа React и Django. Все процессы используют одни settings и одну базу wbwine.sqlite3. Миграции принадлежат ledger. При изменении данных проверяй доступ к объекту по текущему пользователю.

Сначала определи сущности, единицы измерения и инварианты. Atlas и Wild — Python-модули в domain без Django. Их Django-приложения адаптируют записи общей БД и предоставляют операции кабинетам. Числа, влияющие на выбор маршрута, должны иметь источник в данных.

Приоритеты — ёмкость нод в пик и минимизация полной стоимости допустимой цепочки рейсов. Денежная арифметика использует Decimal. Любые изменения брони, загрузки и переходов состояния выполняй атомарно. Демо-данные допустимы в изолированных тестах.

Проверяй изменения через manage.py test ledger, manage.py check, manage.py makemigrations --check и сборку React. При изменении схемы обновляй словарь в README.
